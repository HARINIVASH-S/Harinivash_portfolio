# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/HARINIVASH-S/portfolio.git
```

Move into the project

```bash
cd portfolio
```

Install dependencies

```bash
npm install
```

Run the application

```bash
ng serve
```

Open

```
http://localhost:4200
```

---

# 🚀 Deployment

Build the production version

```bash
ng build
```

Deploy the generated files to

* GitHub Pages
